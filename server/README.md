# Сервер-арена для обучения (Paper 26.1.2)

Отдельный сервер только для ботов (и для автора — поиграть с ними в
салки). Всё, что делает сервер, а не сеть, — здесь и в
`py/training_server.py`: мир под обучение, правила физически, показ.

## Запуск

Кнопка **«Сервер»** в лаунчере (`run_ai_bot.bat`) — или вручную:

```
server\start.bat
```

Команды серверу — в строке команд лаунчера с `/` в начале (по RCON).

Первый запуск Paper сам скачивает официальный `server.jar` Mojang (~60 МБ)
и создаёт плоский мир. Остановить — `stop` в окне сервера.

Подключиться игроку: Minecraft **26.1.2** → «Сетевая игра» → «Прямое
подключение» → `localhost:25566`. Только с этого компьютера (`server-ip`
127.0.0.1): вход без лицензии (`online-mode=false`, иначе боты не зайдут) и
консоль RCON снаружи недоступны.

## Что настраивает Python (py/training_server.py) при подключении

`ai_loop` при старте подключается к серверу по **RCON** (консоль сервера по
сети: `enable-rcon`, порт 25576, пароль — в `server.properties` и в
`config.json → server.rcon`) и сам выставляет:

- правила игры: всегда день, без погоды, мобов, фантомов; сразу респавн,
  вещи остаются. В 26.x правила переименованы (`advance_time`,
  `spawn_mobs`, `keep_inventory`...) — Python пробует новое имя, потом старое;
- точку спавна, границу мира (66 блоков), постоянно загруженную арену;
- **арену** 64x64 (`config.json → server.arena`, раскладка — `py/arena.py`):
  по краю невидимая нерушимая стена из барьера, внутри — уступы в блок,
  стенки в два блока, столбы, кучки земли (быстро копаются — блоки для
  столба). Строится один раз на мир (метка — счёт `#arena` в табло `mcbot`);
  чтобы перестроить — удали папку `server/world` (мир создастся заново);
- **табло**: «Мотивация» (сбоку) — сумма наград каждого бота за последние 5
  минут, ровно то, за что учится сеть; «Очки салок» (в списке игроков, Tab):
  +10 водящему за осаливание, +1 убегающему каждые 10 секунд;
- в салках — роли командами сервера (`/team`: `it` — водящие, красные с
  `[водит]`, `runners` — убегающие, белые), свечение сквозь стены
  (`/effect glowing`), `/kill` застоявшимся, разброс по арене в начале
  раунда (`/spreadplayers`).

Сыграть с ботами самому: `/team join runners <твой ник>` (убегать) или
`/team join it <твой ник>` (водить), в выживании; выйти — `/team leave
<ник>` или режим наблюдателя (его боты не трогают).

Штрафа за выход с арены нет (убран 2026-09-26): по краю стена из барьера,
за ней граница мира — сервер не пускает дальше и наносит урон.

Сервер не отвечает по RCON (выключен, или боты на другом сервере) — всё
работает как раньше, без арены и табло.

## Файлы

- `paper-26.1.2-74.jar` — Paper (скачан с papermc.io, SHA256 сверен);
- `start.bat` — запуск (Java 25);
- `server.properties` — порт 25566, RCON, плоский мир, мирная сложность,
  `spawn-protection=0` (иначе боты не могли бы копать и ставить блоки у спавна);
- `eula.txt` — лицензия Minecraft принята автором.

## Плагин McBot (`server/plugins/mcbot-plugin-*.jar`)

Боты — игроки самого сервера (вместо клиентов mineflayer), если в
`config.json` `bot.body = "plugin"`. Собирается из `plugin/`
(`plugin\gradlew deploy` кладёт jar сюда, в `plugins/`); подхватывается при
запуске сервера. Боты заходят по `/mcbot start` (лаунчер шлёт сам по RCON),
уходят по `/mcbot stop`. Подробно — README.md проекта, раздел «Боты в
плагине сервера».

## Команды при запуске задачи (`server/functions/`)

`<задача>.mcfunction` (например, `hunt.mcfunction`, `tag.mcfunction`) —
команды сервера по одной на строку, `#` — комментарий, `/` в начале не
нужен. Python (py/training_server.py: `run_function`) выполняет их по RCON,
когда рой начинает задачу (запуск лаунчера с ней или `!task all <задача>`)
и все боты уже зашли. Ошибки команд — в лог (`[server] команда -> ответ`).
Синтаксис 26.1: зачарования — без `levels`: `wooden_sword[enchantments={sharpness:255}]`.
